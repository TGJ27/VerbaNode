# Example Echo

This is the reference external plugin included with VerbaNode v0.6.2.

1. Open **Agents** and enable `example_echo` for the active agent.
2. Open **Plugins** and confirm the plugin is globally enabled.
3. Say or type: `Echo external plugins are working.`

Expected response:

```text
external plugins are working.
```

Copy this folder when starting a new plugin, then change the manifest ID, metadata, schema, matching logic, and execution handler.
